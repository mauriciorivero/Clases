Crea package.json con npm init

npm init te hace preguntas y guarda las respuestas en package.json: nombre, versión, archivo de entrada, scripts y, más adelante, las dependencias.

Paso 5 de 9hash

          
Convierte una contraseña en hash

          
encryptPassword recibe un texto y devuelve su hash: una huella de 40 caracteres que siempre es la misma para la misma entrada.

          
    
            
  • Escribe en la consola de la derecha. Cambia una sola letra y el hash cambia casi por completo.
    • 
            
  • Un hash no se puede revertir. Por eso no existe una función decryptPassword.
    •

Paso 6 de 9hash

          
Verifica una contraseña

          
Para saber si alguien escribió la contraseña correcta no comparas textos. Hasheas lo que escribió y lo comparas con el hash guardado.

          
    
            
  • Si los dos hashes son iguales, la contraseña es correcta.
    • 
            
  • El sistema solo guarda el hash. La contraseña original nunca queda escrita.
    • 
            
  • La contraseña guardada en la consola es Clave123. Corrige la que está escrita hasta que coincida.
    •

    Cierre
    
          
    Un hash no es cifrado
    
          
    object-hash calcula huellas: sirven para comparar datos, no para esconderlos. Cifrar es reversible con una clave; un hash no se puede revertir.
    
          
      
            
    • MD5 y SHA-1 son rápidos, y para contraseñas eso es un problema: un atacante puede probar miles de millones por segundo.
      • 
            
    • bcrypt agrega una sal aleatoria y es lento a propósito. Es la opción para guardar contraseñas reales.
      •
